# Производительность: изображения, шрифты, бюджет JS, CWV (task 39)

Дата замеров: 2026-10-21. Цели ТЗ §2 п.3 (мобильные): **LCP < 2,5 с, CLS < 0,1, INP < 200 мс**; бюджет JS
**≤ 150 КБ gzip на маршрут**.

## Итог в двух словах

- **CLS** — цель выполнена на всех маршрутах (0,000–0,021; максимум — статья).
- **JS** — сокращён на 40–88 КБ gzip на маршрут (базовая страница 258 → 170 КБ, страницы catch-all 267 → 188 КБ), но бюджет 150 КБ
  **не достигнут**: рантайм Next 16 + React 19 сам по себе весит **129 КБ gzip** (см. «JS-бюджет»).
  Для e2e-контроля регрессий введён временный потолок **245 КБ** (`JS_CEILING_GZIP_BYTES`
  в `scripts/perf/routes.ts`) — **требует согласования координатором**.
- **LCP / TBT** (лабораторный Lighthouse, slow 4G + CPU ×4) — улучшены на большинстве маршрутов (LCP до −1,5 с, TBT до −430 мс,
  Performance до 85–91 на конструкциях, справочных страницах, объекте, поиске), но цели (LCP < 2,5 с,
  TBT ≤ 200 мс) **не достигнуты** ни на одном шаблоне. Причина — время выполнения JS до первой отрисовки
  (см. «Остаточные проблемы»). Окончательная оценка — RUM и staging (task 42).

## Остаточные проблемы

1. **LCP 3,5–4,5 с и TBT 400–700 мс в лаборатории.** В трассе Lighthouse все ресурсы загружены к ~0,4 с,
   а первая отрисовка — ~1,2 с: асинхронные чанки успевают загрузиться до первого кадра и выполняются до него;
   Lantern переносит это на slow 4G + CPU ×4. Рычаги: меньше JS (см. выше) и меньше HTML (главная — 330 КБ
   без сжатия, большая часть — дублирующий RSC-payload).
2. **Почти все фиксированные маршруты динамические (`ƒ`, `Cache-Control: no-store`)** — `/`, хабы, `/blog/`,
   `/kontakty/`… Причина: `assertDbAvailableOrBailOut()` (`src/lib/cms/cache.ts`) вызывает `connection()` при
   сборке без БД, и Next 16 помечает маршрут динамическим целиком, а не «ISR по первому запросу», как
   предполагает комментарий в файле. Каждый запрос рендерится заново (данные CMS из `unstable_cache`, но
   SSR каждый раз) — TTFB на VDS под нагрузкой вырастет. Нужна отдельная задача (владелец `lib/cms`): например,
   рендер при первом запросе через `generateStaticParams`-эквивалент или сборку с доступом к БД.
3. `favicon.ico` 26 КБ запрашивается с высоким приоритетом — уменьшить (ассет брендинга, вне задачи).
4. EXIF в 49 уже загруженных оригиналах dev-медиатеки (см. «Изображения»).
