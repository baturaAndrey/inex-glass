## 1. `/kak-zakazat/` — хаб «Как заказать»

**Работа клиента:** понять весь путь заказа за 30 секунд и перейти к нужному шагу. Тип — навигационный хаб процесса (TGA support_hub).

**Блоки:**
1. **6 шагов на одном экране** (каждый — ссылка на страницу):
   1. Файл: DWG / DXF, для простых стёкол — PDF или эскиз → «Требования к чертежам»
   2. Проверка и спецификация на согласование; отклонения согласуем до производства → «Допуски и ГОСТ»
   3. КП с ценой, сроком, доставкой — в среднем за 2–3 рабочих дня → «Расчёт стоимости»
   4. Договор → срок в рабочих днях отсчитывается от даты договора → «Сроки»
   5. Производство на заводах-партнёрах; статус — звонок и e-mail менеджера
   6. Упаковка (по согласованию), фото при отгрузке, доставка ТК → «Упаковка и доставка» → «Приёмка» → «Документы»
2. **Условия одной строкой:** минимальный заказ 50–100 м² · срочного изготовления нет · монтаж не выполняем · физические шаблоны не принимаем [факт].
3. **Кто за что отвечает** — таблица: ошибка завода → переделка за счёт Inex; ошибка в согласованном чертеже → за счёт клиента; доставка повторной партии → клиент [факт].
4. CTA: «Рассчитать стоимость» · «Загрузить чертёж».

**Meta:** Title «Как заказать закалённое стекло для проекта — 6 шагов | Inex Glass» · Description «От чертежа DWG до доставки: проверяем файл и согласуем спецификацию до запуска, срок — от даты договора. Заказы от 50 м².»

## 3. `/kak-zakazat/dopuski-i-gost/` — Допуски по ГОСТ 30698-2014

### A1
| Поле | Содержание |
|---|---|
| Пользователь | Конструктор, инженер, проектировщик крупных объектов |
| Ситуация | Закладывает зазоры, отверстия и узлы под фурнитуру |
| Решение | Какие отклонения считать нормой, как расположить отверстия, что считать браком |
| Главный риск | «Это в ГОСТе» как отговорка (P03); фурнитура не встаёт; спор при приёмке |
| Действие | Учесть правила в чертеже; при приёмке — проверить по тем же правилам |

### Блоки (все цифры — SSoT §11)
1. **Короткий ответ:** работаем по ГОСТ 30698-2014; ниже — все допуски, которые влияют на чертёж и приёмку.
2. **Допуски длины и ширины** — таблица: до 2000 мм — ±2 / ±3 мм (толщина до 12 / свыше 12); 2000–3000 — ±3 / ±4; свыше 3000 — ±4 / ±5. Для сложной формы — по чертежу, согласованному в спецификации. [**сверить таблицу с оригиналом ГОСТ** — распознанный текст повреждён]
3. **Плоскостность** — общее и локальное отклонение по толщинам.
4. **Отверстия** — схема из 3 правил (от кромки ≥ 2t, между отверстиями ≥ 2t, от угла ≥ 6t) + **калькулятор-подсказка**: ввёл толщину → получил минимальные расстояния (для 10 мм: 20 / 20 / 60 мм). Допуск диаметра ±1 мм (Ø 4–20), ±2 мм (Ø 20–100); диаметр меньше толщины стекла — по согласованию; кромки отверстий притупляются.
5. **Как закладывать зазоры** — практический вывод: допуск ±2 мм → зазор под монтаж и регулировку фурнитуры закладывается в чертёж [интервью, Саша: «фурнитура должна скомпенсировать допуски»].
6. **Что считается дефектом и как проверяют** — визуальный осмотр кромок, отверстий и вырезов при освещённости 300–600 лк с 0,6–1 м; сложная форма проверяется по шаблону или чертежу (пп. 9.3.1, 9.8) → «Приёмка».
7. **Линзы и оптические искажения** [факт, ГОСТ 30698-2014 п. 5.1.7, метод 9.12.1]: искажения, видимые в проходящем свете под углом ≤ 30° на экране «кирпичная стена», не допускаются; в отражённом свете, а также у узорчатого и моллированного стекла и стёкол с пропусканием < 30% — не нормируются; проверка по ГОСТ 33003-2014. Практический вывод для клиента: «линза», заметная только в отражении или под острым углом, браком по ГОСТ не считается [интервью: 2 из 3 клиентов сталкивались — Павел (лифтовая шахта), Саша (спор с заказчиком, снят лабораторией)]. Сверить формулировку с Изменением № 1 (2025).
8. CTA: «Загрузить чертёж на проверку».

**Meta:** Title «Допуски закалённого стекла по ГОСТ 30698-2014 — размеры и отверстия | Inex Glass» · Description «±2 мм до 2000 мм, отверстие не ближе двух толщин стекла к кромке и шести — к углу. Таблицы и калькулятор для чертежа.»

**Метрики:** использование калькулятора отверстий · переход в загрузку чертежа · доля заявок, вернувшихся на доработку из-за отверстий.

## 4. `/raschet-stoimosti/` — квиз «Расчёт стоимости» (ТЗ для разработки)

Квиз открывается со всех страниц (кнопка «Рассчитать») и живёт отдельной страницей. Предзаполняется из контекста: со страницы толщины — толщина; со страницы вида — вид стекла; с конструкции — тип изделия.

### Цели
1. Отсечь нецелевые заявки (розница, обычное стекло, срочно, малый объём) — **до отправки**, вежливо.
2. Собрать всё, что нужно менеджеру для КП без лишнего звонка.
3. Показать ориентир цены (если введены площадь и толщина) — без обещания.

### Шаги и поля

| Шаг | Поле | Тип | Проверка / ветвление |
|---|---|---|---|
| 1. Что нужно | Тип: закалённое стекло / триплекс / стеклопакет / конструкция (перегородка, ограждение, душевая, козырёк, фасад, торговая витрина, зеркала) / специальное стекло | выбор | — |
| 2. Стекло | Толщина: 4, 5, 6, 8, 10, 12, 15, 19 мм / «подберите под нагрузку» | выбор | «Подберите» → поле «Опишите конструкцию и нагрузку» |
|  | Вид: прозрачное, осветлённое, матовое, тонированное (цвет), крашеное (RAL), рифлёное, гнутое | выбор | крашеное → толщина 4–15, размер ≤ 3000 × 1600; гнутое → толщина 4–12, размер ≤ 1200 × 2000, поле «радиус» (≥1000 / ≥1500 мм) |
| 3. Объём | Количество позиций, общая площадь, м² | число | **< 50 м² →** сообщение «Мы работаем с заказами от 50 м². Можем объединить с другими позициями вашего проекта — оставьте контакты» (заявка не блокируется, но помечается «малый объём») |
|  | Максимальный размер стекла, мм | 2 числа | вне 150 × 300 — 3000 × 2000 → «Нестандартный размер — менеджер уточнит возможность» |
| 4. Обработка | Кромка: шлифовка / полировка / «трапеция» / «еврокромка» / фацет (ширина) | мультивыбор | — |
|  | Отверстия: есть / нет; количество; диаметры | выбор + числа | Ø вне 4–130 → подсказка (до 220 — с одной стороны); показать правило «от кромки ≥ 2t, от угла ≥ 6t» для выбранной толщины |
|  | Обработка отверстий изнутри (притупление / зенкование) | да / нет | — |
|  | Вырезы, пазы, фрезерование | да / нет | — |
|  | Матирование, печать (≤ 1100 × 700), плёнка | мультивыбор | печать вне размера → подсказка |
|  | Клеймо: стандартно / указать место / без клейма | выбор | — |
|  | Heat Soak Test | да / нет | подсказка: «рекомендуем для фасадов и ограждений» |
| 5. Файл | Загрузка: DWG, DXF; для простых стёкол — PDF, фото эскиза | файл, до 50 МБ | без файла можно продолжить, если все стёкла прямоугольные |
| 6. Сроки и доставка | Желаемая дата готовности | дата | раньше чем через 10 рабочих дней (14 — триплекс) → «Срочного изготовления нет. Ближайший срок — от 10 рабочих дней с даты договора» |
|  | Город доставки | список 13 городов + «другой» | — |
|  | Требования к упаковке | текст / чекбоксы (плёнка, картон, ящик под кран) | — |
|  | Нужен пакет документов (паспорт, сертификат, протоколы) | да / нет | — |
| 7. Контакты | Компания, ИНН (необязательно), имя, телефон, e-mail, роль (подрядчик / производитель / застройщик / дизайнер / другое) | текст | согласие на обработку ПДн (152-ФЗ) |

### Подсказка акции
Если площадь ≥ 100 м² — показать «Для заказов от 100 м² действует скидка 5%» (поле акции из CMS; не показывать после даты окончания).

### Ориентир цены (после шага 3)
`площадь × цена «от» для толщины` из справочника цен (SSoT §1.1), подпись: «Ориентир без обработки и доставки, цены на ДД.ММ.ГГГГ. Точная стоимость — в КП». Если дата цены старше 45 дней или толщина 15/19 мм — ориентир не показывать.

### Передача в CRM
Все поля + страница входа, UTM-метки, флаги: «малый объём», «нестандартный размер», «срочно», «без файла», «нужны документы»; файл — вложением. Менеджеру — уведомление.

### После отправки
Экран: «Спасибо! Менеджер проверит данные и пришлёт КП — в среднем за 2–3 рабочих дня, для больших объёмов дольше. Связь — звонком и по e-mail». [факт]

### Метрики
Доля начатых → завершённых квизов · доля заявок с файлом · доля флагов «малый объём» / «срочно» (нецелевые) · время от заявки до КП · конверсия КП → договор.
