### A1
| Поле | Содержание |
|---|---|
| Пользователь | Подрядчик по отделке офисов и ТЦ, генподрядчик, застройщик, дизайнер коммерческих интерьеров |
| Ситуация | Нужно зонировать офис, ТЦ, банк, медцентр; есть планировка и высоты |
| Решение | Какую систему перегородок (цельностеклянная / в алюминиевом профиле / раздвижная) и какое стекло выбрать |
| Главный риск | Перегородка не встанет из-за допусков пола и потолка; стекло не того типа для высоты; нет документов для сдачи объекта |
| Действие | Отправить планировку и высоты → КП на комплект |

### Порядок блоков
1. **Первый экран:** H1 «Стеклянные перегородки для офисов и коммерческих объектов»; подзаголовок: проект узлов, стекло, профиль и фурнитура одним комплектом · заказы от 50 м² · монтаж — ваша бригада; кнопки «Рассчитать комплект» · «Отправить планировку».
2. **Типы систем — сравнение** (таблица по сценариям, GIST F2): цельностеклянная (в зажимном профиле, минимум металла) · в алюминиевом профиле (каркас, двери, звукоизоляция) · раздвижная · с дверью (маятниковые / распашные). Для каждой: где уместна, ограничения, что входит в комплект [данные систем — **уточнить у Inex**: какие профильные системы поставляете].
3. **Стекло для перегородки:** толщина и триплекс подбираются под высоту и сценарий (Inex подбирает расчётом) [факт]; осветлённое для видимого торца; матовое / пескоструй с логотипом для переговорных [факт: виды есть].
4. **Скрытый узел — допуски проёма:** перепад пола, неровность потолка, монтажные зазоры; почему стекло режется по замеру после чистовой отделки, а не по проекту [интервью, Саша: заказ после контрольных шаблонов] → «Как снять размеры».

6. **Документы для сдачи объекта** — паспорт, сертификат, протоколы [факт] → «Документы».
7. **Объекты** — офисные и ТЦ-перегородки из портфолио inex.su (банки, ТЦ, «Сургутнефтегаз», «Трактор» арена) [факт: можно показывать все].
8. **Нужен монтаж под ключ?** — мост на inex.su [уточнить: направлять ли туда частных и тех, кому нужен монтаж].
9. FAQ: высота без каркаса; можно ли с дверью; сроки (от 10 р.д. с даты договора); от какого объёма; что входит в комплект.

**Title:** «Стеклянные перегородки для офисов — комплект с проектом узлов | Inex Glass»

## 5. `/kak-zakazat/priemka/` — Приёмка

**Работа клиента:** принять партию на объекте так, чтобы при дефекте не остаться без компенсации («кто виноват» — P04, P09).
**Блоки:**
1. **До подписания накладной:** осмотреть ящики, при повреждении упаковки — фото и отметка в накладной у водителя [знание отрасли / интервью; ✅ совпадает с практикой арбитража из карты болей: явные дефекты — до подписания ТТН].
2. **Как проверять стекло** — по методу ГОСТ 30698-2014: кромки, отверстия и вырезы осматривают при освещённости 300–600 лк с 0,6–1 м; сложную форму — по чертежу; линзы — по п. 5.1.7 [факт].
3. **Скрытые дефекты** — в какой срок сообщить [уточнить срок по договору Inex].
4. **Кто платит:** ошибка завода — переделка за счёт завода; ошибка в согласованном чертеже — за счёт клиента; повторную доставку оплачивает клиент [факт].
5. **Зимой** — распаковывать после выравнивания температуры [интервью, Илья; проверить у технолога].
6. Скачать: чек-лист приёмки (PDF, 1 страница).
