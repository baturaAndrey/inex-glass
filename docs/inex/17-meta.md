# Inex Glass — title, description, H1 для всех страниц

Версия от 15.10.2026. Правила (GIST, модуль E):
- **Title:** главный запрос страницы — в начале; одно отличие (стабильный факт); бренд в конце; ориентир — до 60–65 знаков.
- **Description:** не повторяет title, добавляет доказательство, условие или действие; 120–160 знаков; главный факт — в первых 90 знаках.
- **Цены и акции** в title и description — только на карточках толщин и только из справочника CMS (`{цена}`); при просроченной цене — вариант без цены.
- Спрос — точная частотность запросов страницы в месяц в трёх округах (Урал, Сибирь, Поволжье).
- Длины проверены скриптом — см. последний столбец в Word-версии.
