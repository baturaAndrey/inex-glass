# Inex Glass — техническое задание на разработку сайта

Версия 1.0 от 15.10.2026. Документ для разработчиков и дизайнера. Собран из согласованной структуры (утверждена директором Inex 15.10.2026), технических данных Inex и структур страниц.

## 1. О проекте

- **Inex Glass** — новый сайт направления инжиниринговой компании Inex (Челябинск): комплектация проектов закалённым стеклом и стеклянными конструкциями. Стекло изготавливают заводы-партнёры в России и Китае, Inex проектирует, проверяет чертежи, размещает заказ, контролирует изготовление и упаковку, отправляет на объект. **Монтаж не выполняется.**
- **Аудитория — B2B:** подрядчики и монтажники, производители мебели и изделий из стекла, генподрядчики крупных объектов, застройщики, дизайнеры и архитекторы.
- **География:** Урал, Сибирь, Поволжье, Север. Городских версий и городских посадочных страниц **нет**.
- **Домен:** **inexglass.ru** (зарегистрирован). Стеклянные разделы inex.su переезжают на новый домен с постраничными 301-редиректами (раздел 9).
- **Главная конверсия:** заявка через квиз «Расчёт стоимости» с загрузкой чертежа → модуль заявок (CRM внутри сайта, раздел 6.1) → КП менеджера.
- **Платформа:** самописная CMS; справочники, портфолио и цены ведёт **администратор сайта**.

## 2. Общие требования

1. **Самописная CMS** с редактируемыми справочниками (раздел 4) и ролями: администратор (всё содержимое, справочники, цены, портфолио), менеджер (только модуль заявок) — значения выводятся на всех страницах из одного места, без ручного дублирования в текстах.
2. Адаптивная вёрстка (смартфон, планшет, десктоп); первый экран каждой страницы содержит кнопку «Рассчитать стоимость».
3. Скорость: целевые значения Core Web Vitals «хорошо» на мобильных (LCP < 2,5 с, CLS < 0,1, INP < 200 мс).
4. HTTPS, корректные коды ответа (200 / 301 / 404), собственная страница 404 с поиском и ссылками на разделы.
5. Хлебные крошки на всех страницах кроме главной — по структуре URL (один родитель у каждой страницы).
6. Тексты не содержат названий заводов-партнёров.

## 3. Структура и URL

**Правила URL:** латиница в нижнем регистре, транслит, слова через дефис, **слеш на конце**; один адрес — одна страница; адрес с другим регистром или без слеша — 301 на канонический.

**Индексация:** «index» — страница открыта для поиска; «noindex» — `<meta name="robots" content="noindex, follow">`, страница доступна людям и не участвует в поиске.

## 6. Квиз «Расчёт стоимости» и формы

Полное ТЗ квиза — `gist/p0-dokumenty-gost-kviz.md`, раздел 4. Ключевое:

- 7 шагов: что нужно → стекло (толщина, вид) → объём и размеры → обработка → файл → сроки и доставка → контакты.
- **Проверки по справочнику 4.5**; при выходе за ограничения — подсказка, а не блокировка.
- **Объём < 50 м²** — сообщение «работаем с заказами от 50 м²», заявка уходит с флагом «малый объём».
- **Дата раньше 10 рабочих дней** (14 — триплекс) — сообщение «срочного изготовления нет», флаг «срочно».
- Опции: обработка отверстий изнутри; клеймо — стандартно / указать место / без клейма; требования к упаковке; пакет документов.
- **Файлы:** DWG, DXF, PDF, JPG/PNG (эскиз), до **50 МБ**.
- **Ориентир цены:** площадь × цена от для толщины (справочник 4.1) с подписью-оговоркой; не показывается при просроченной дате и для 15 / 19 мм.
- **Подсказка акции** при площади ≥ 100 м², если акция активна.
- **После отправки:** «Менеджер проверит данные и пришлёт КП — в среднем за 2–3 рабочих дня. Связь — звонком и по e-mail».
- **Передача в CRM:** все поля, файл, страница входа, UTM-метки, флаги («малый объём», «нестандартный размер», «срочно», «без файла», «нужны документы»), уведомление менеджеру. Заявки попадают в модуль заявок внутри сайта (раздел 6.1).
- Согласие на обработку персональных данных (152-ФЗ): чекбокс **не отмечен по умолчанию**, без отметки форма не отправляется; ссылки на страницу согласия и на политику. Тексты — teksty/15-politika-pdn.md (проект, утверждает юрист Inex).
- **Баннер о cookie** при первом визите (текст там же). Если юрист потребует отдельное согласие на аналитику — кнопки «Принять» / «Только необходимые», Яндекс.Метрика загружается только после «Принять».

### 6.2. Страница заказа по ссылке (без личного кабинета)

Задача — клиент видит статус заказа и фото упаковки без звонка менеджеру и без регистрации. Закрывает боли из интервью: «о переносе срока узнаю, когда звоню сам», споры об упаковке. **Условие запуска — согласие Inex:** менеджеры обновляют статус и загружают фото упаковки при каждой отгрузке.

| Функция | Требование |
|---|---|
| Создание | Когда заявка переходит в статус «Договор», модуль создаёт заказ и уникальную ссылку `inexglass.ru/zakaz/<код>` — длинный случайный код, не номер заказа |
| Доступ | Без логина, по ссылке; страница закрыта от индексации (noindex, запрет в robots.txt); ссылку можно отозвать или перевыпустить в админ-панели |
| Статусы заказа | Спецификация согласована → В производстве → Упаковано → Отгружено → Получено; у каждого статуса — дата; менеджер может добавить комментарий для клиента (например, о переносе срока с новой датой) |
| Уведомления | При каждой смене статуса клиенту уходит письмо со ссылкой на страницу |
| Фото упаковки | Менеджер загружает фото при статусе «Упаковано» или «Отгружено»; на странице — галерея с увеличением |
| Отгрузка | Транспортная компания и номер накладной (поле в админ-панели) |
| Документы | Спецификация, паспорт и сертификаты на партию — файлы для скачивания |
| Менеджер | Имя, телефон, e-mail, кнопка «Написать» в мессенджер |
| Персональные данные | На странице нет телефона и e-mail заказчика — только номер заказа, компания и состав |
| Срок жизни ссылки | [90] дней после статуса «Получено», затем страница недоступна; срок задаёт администратор |

Чат с менеджером на сайте **не делаем**: клиенты пишут в мессенджеры и звонят, а чат требует дежурства онлайн.

### 6.3. Этап 2: личный кабинет (после запуска, по условиям)

Не входит в первый этап. Решение о разработке — через 2–3 месяца работы страницы заказа (6.2), если одновременно:
- менеджеры стабильно ведут статусы и фото во всех заказах;
- заметная доля заказов — от постоянных клиентов (история заказов, повтор по тем же чертежам, документы в одном месте);
- клиенты сами просят доступ к истории заказов.

Кабинет строится поверх того же модуля заявок и страниц заказа: вход по e-mail (код подтверждения вместо пароля), список заказов компании, повтор заказа, документы по всем партиям.

## 7. Калькуляторы

1. **Вес стекла** (`/instrumenty/kalkulyator-vesa-stekla/`): 2,5 кг/м² на 1 мм толщины; одинарное / триплекс (сумма стёкол + плёнка EVA: 0,36 кг/м² на слой 0,38 мм); вход — толщины, размеры, количество; выход — вес 1 м², одного стекла, партии; кнопка «Посчитать стоимость» передаёт параметры в квиз.
2. **Расстояния для отверстий** (на `/kak-zakazat/dopuski-i-gost/` и `/obrabotka-stekla/otverstiya-i-vyrezy/`): ввод толщины → минимальные расстояния от кромки (2t), между отверстиями (2t), от угла (6t) и допуск диаметра (±1 мм для Ø 4–20, ±2 мм для Ø 20–100).

## 8. Техническое SEO

1. **Title, description, H1** — редактируемые поля у каждой страницы; для карточек толщин и видов — шаблоны с подстановкой из справочников (таблица мета — отдельным документом).
2. **Canonical** на самой странице; у фильтров и пагинации — по правилам ниже.
3. **noindex, follow:** карточки 5, 15, 19 мм; страницы фильтров объектов; страницы результатов поиска; служебные (политика ПДн, «спасибо»).
4. **Пагинация** листингов (объекты, блог): страницы 2+ — index, follow, canonical на себя, в title — «страница N».
5. **sitemap.xml** — только индексируемые страницы, с датой изменения; обновляется автоматически.
6. **robots.txt:** закрыть служебные и параметрические адреса (поиск, UTM, фильтры), указать sitemap.
7. **Микроразметка (Schema.org, JSON-LD):** Organization (Inex Glass), LocalBusiness — для офисов Челябинска и Екатеринбурга; BreadcrumbList — везде; Product + AggregateOffer (lowPrice из справочника, RUB) — на карточках толщин, **только пока дата цены не просрочена**; FAQPage — на страницах с FAQ; Article — на статьях.
8. **Изображения:** WebP/AVIF, атрибуты alt, ленивая загрузка ниже первого экрана.
9. **Яндекс.Вебмастер и Google Search Console** — подключить до запуска; в Вебмастере указать регион сайта по местоположению офиса (Челябинск).
