# Комплект для разработчиков Inex Glass

1. **Inex-Glass-TZ-razrabotka.docx** — техническое задание (то же в 16-tz-razrabotka.md). Начинать с него.
2. **15-ssot-tehnologiya.md** — все факты и цифры для справочников CMS, квиза и калькуляторов.
3. **12-migration-inex-su.csv / .md** — карта 301-редиректов с inex.su и порядок переезда.
4. **13-homepage.md** — структура и тексты главной.
5. **Inex-Glass-meta-teg.docx** (и 17-meta.md) — title, description и H1 для всех страниц; шаблоны с {цена} и {N} подставляются из справочников CMS.
6. **struktury-stranic/** — структуры страниц (что на странице, в каком порядке, title, description):
   - hub-zakalennoe-steklo.md — хаб «Закалённое стекло»
   - p0-kartochki-tolshchin.md — карточки толщин
   - p0-servisnye.md — требования к чертежам, сроки, упаковка и доставка
   - p0-dokumenty-gost-kviz.md — «Как заказать», документы, допуски и ГОСТ, **ТЗ квиза** (раздел 4)
   - p0-o-kompanii-kontakty.md — о компании, контакты
   - p1-*.md — страницы второй очереди

Пометки [уточнить] в файлах — вопросы, на которые Inex ещё отвечает; на вёрстку и разработку они не влияют.

**Изменения 19.10.2026.** Удалены разделы «Стеклопакеты» и «Специальные стёкла», статьи о ГОСТ 24866 и Heat Soak Test; Heat Soak Test не выполняется (убран и из квиза). Фацет — только на зеркалах. Если структура страницы противоречит ТЗ или 17-meta.md, верны ТЗ и мета-теги.
