## Technical Details

### Общие правила среза

- Next.js 16.4, `trailingSlash: true`, `cacheComponents` выключен; данные через `@/lib/cms/*` с тегами; цен нет → `revalidate = 3600` избыточен, но допустим; build без БД.
- Тексты дословно из teksty; H1/title/description — из `docs/inex/17-meta.md`; заголовок `#` в teksty, отличающийся от 17-meta, не выводится. Метки `{…}` остаются в данных. Стоп-слова ТЗ §11 (в т. ч. «монтаж под ключ» допустим **только** в связке с inex.su) запрещены. Название «Фристайл» — как в дозапросе 19.10.
- Только светлая тема; CSS прототипов (`p5-*`) переписывается на Tailwind; брейкпоинты 1365 / 1100 / 599; Lucide stroke 2; без эмодзи.
- Первичная кнопка hero **всегда** с иконкой calculator и ведёт в квиз с предзаполнением; подписи разные («Рассчитать комплект», «Рассчитать партию», «Рассчитать козырёк», «Рассчитать стоимость»).
- Правило обновления в сиде: срез обновляет существующий документ по `slug`, только если передан `--force` **или** документ не редактировался (|`updatedAt` − `createdAt`| < 2 с — его создал мини-сид); иначе пропуск с записью в лог. `pnpm seed --only=constructions` идемпотентен.

### Контракт `ConstructionPage` и разрешение документа

`resolveConstruction({ slug, path })`: (1) если задан `path` — документ по полю `path`; (2) иначе документ по `slug`; (3) если не найден — «ключ пути»: документ, у которого `path` без начального/конечного слеша с заменой `/` на `-` равен переданному `slug` (так `slug='osteklenie-fasadov'` находит документ с путём `/osteklenie/fasadov/`; список путей — один кэшируемый запрос `collection:constructions`). Только опубликованные. Для семи URL этой задачи `slug` документа равен последнему сегменту URL. Рекомендация для task-27: slug документа = последний сегмент (`fasadov`), родитель — хаб `osteklenie`; шаблон поддерживает и эту схему, и «ключ пути».

`generateConstructionMetadata` → `buildMetadata({ seo: doc.seo, path: doc.path, fallbackTitle: doc.title, placeholders: await getPlaceholderContext() })`.
