## Technical Details

### Общие правила среза

- Next.js 16.4, `trailingSlash: true`; `cacheComponents` выключен; данные через `@/lib/cms/*` (кэш с тегами `collection:glass-types`, `doc:glass-types:<id>`, `global:snippets` …). Страницы не зависят от `now` (цен нет) → `export const revalidate = 3600` на `/tripleks/` не нужен; `generateStaticParams → []`, `dynamicParams = true` (build без БД).
- Тексты дословно из teksty (`08-vidy-stekla.md`, `16-riflenoe.md`, `12-p2-konstrukcii-steklo.md` §5 и §6); мета — `docs/inex/17-meta.md`; метки `{…}` остаются в данных. Стоп-слова ТЗ §11 (стеклопакет, Heat Soak/HST, бронированное, смарт, антиблик, «шпион», названия заводов, «собственное производство» и т. п.) не допускаются. Фацет — только на зеркалах (SSoT §13).
- Только светлая тема; CSS прототипов (`ct-*`, `vd-*`, `th-*`) переписывается на Tailwind; брейкпоинты 1365 / 1100 / 599; Lucide stroke 2; без эмодзи.
- Правило обновления в сиде: срез обновляет существующий документ по ключу `slug`, только если передан `--force` **или** документ ещё не редактировался (|`updatedAt` − `createdAt`| < 2 с — его создал мини-сид); иначе пропуск с записью в лог. Запуск: `pnpm seed --only=glass-types`; повторный прогон не создаёт дублей.

### Шаблон `GlassTypePage` — порядок секций

Фоны секций чередуются `--ig-bg` / `--ig-surface` (счётчик в шаблоне); отступы `.blk` 96 / 72 / 48; контейнер с полями `--ig-gutter`; ритм сохраняется и на `layout`-блоках (в сиде у них явный `background`).

1. **Hero** (`PageHero variant="ct-hero"`, макет — `Osvetl.dc.html`, `Riflenoe.dc.html`): крошки; `h1` (`seo.h1`); `facts` = `intro` (Lexical, `{условия}` подставляется) — абзац 18 px, `max-width 820`; primary-кнопка `l` «Рассчитать стоимость» (иконка calculator, `QuizLink` с `prefill` из `quizPrefill` и `src = path`; текст из `quizPrefill.ctaLabel`); `terms` = полоса условий `Terms` из `conditions.termsBarShort`; `aside`: если есть `heroPhotos` — `EdgeCompare` (две карточки `Placeholder`/картинка с подписями-`figcaption`, 3:4, `rounded-lg`) либо одна фото-карточка; при их отсутствии — одноколоночный hero. `heroImage` (если задано) — фон-иллюстрация справа (`next/image`, `preload` (Next 16; `priority` устарел), `sizes`).
2. **Варианты** (`variantsHeading` как `h2`): если у любого варианта задано `application` — интерактивный выбор (`VariantsPicker`, как в `Riflenoe.dc.html`: сетка 5 колонок ≥1366 → 3 при ≤1100 → 2 при ≤599, радио-карточки `role="radiogroup"`/`radio`, roving tabindex и стрелки, выбранная — рамка primary и фон primary-light; ниже панель `aria-live="polite"` из двух колонок: слева `name` + `description`, справа «Где чаще применяют» + `application`; ≤599 одна колонка, мелкое описание в карточках скрыто); иначе — статичная сетка карточек (образец + название + описание), как цвета тонированного. Образец: `swatchKind=image` → `swatchImage`, `color` → `swatchColor` (квадрат, `rounded-md`), `pattern` → CSS-паттерн по `patternKey` (порт `.vd-sw--moru|fluts|shin|delta|kriz` из `Riflenoe.dc.html`). Затем `variantsNote` (richText, абзац) и `variantsCallout` (`Callout variant="info"`, `title` необязателен, `body` richText).
